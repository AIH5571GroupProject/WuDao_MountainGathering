# 武道山集 · 高山探索 Demo 与后续路径

## 工作方式判断

先做连续的空间体验，再定镜头和粒子美术。静态分镜不足以证明山体是否高、人物是否突出、镜头是否穿山，或者拉远返回是否自然。今后如需分镜，应从真实交互场景中截取关键状态，作为沟通记录。

本轮在现有 Vite / React / TypeScript / Three.js / R3F 项目里实现可操作的空间样机。山体、竹林、人物与空气点使用程序几何，均为真正的三维坐标；粒子运动和人物占位动作在 GPU 上计算。没有使用山林底图，没有生成新的视频或设计分镜。

尚未接入 World Labs 的 SPZ / PLY。当前样机验证空间与交互，不代表最终高斯资源、美术或电影动作已经完成。World Labs 更适合后续提供经过布局控制的局部竹林环境；整座山与五场地应继续由可控的空间布局管理。

## 空间组织

一座主峰、五个不同海拔的空地。场地中心被真实压平，周边竹丛避开空地，不是浮在地图上的五张标签。远近视角共用同一台透视相机与同一组世界坐标。

| 场地 | 场所 | 地形定位 | 近场视觉 |
| --- | --- | --- | --- |
| 少林 Shaolin | 松风院 | 较高的山肩 | 双人主体、疏竹、淡绿色气流 |
| 咏春 Wing Chun | 听竹坪 | 面向山外的竹坡 | 双人主体、近身动作占位 |
| 跆拳道 Taekwondo | 云石台 | 靠近高处的石台 | 双人主体、较开阔的云雾背景 |
| 拳击 Boxing | 回声谷 | 山侧谷口 | 双人主体、脚步节奏占位 |
| 相扑 Sumo | 大地席 | 山前较低的平台 | 双人主体、稳定的空地与环形粒子 |

当前五处近场共用同一套可替换的占位人物与环境构造。文案和配置独立；正式电影场景后续逐区替换，不为每一区重新写一套导航。

## 体验状态

`overview → approach → arena → details`

退出由 `arena / approach / details → returning → overview` 完成。快速换场会替换当前镜头命令，旧场地的到达回调不会误改新状态。

| 状态 | 画面主体 | 操作 | 反馈与边界 |
| --- | --- | --- | --- |
| 高山总览 | 高峰、山路、五片空地 | 左键拖动环看、右键平移、滚轮靠近/拉远 | 旋转高度与距离有限，避免把山翻倒或完全丢失 |
| 空地悬停 | 当前空地轮廓与名字 | 点击入口，或悬停入口向前滚动 | 空地圈轻呼吸、附近点加深，触发靠近音乐接口 |
| 靠近 | 真实山坡与目标空地 | 镜头沿曲线下降；允许直接选另一处场地或 Esc 退出 | 镜头持续检查离地高度，后半程才将远山淡成抽象背景 |
| 人物主场 | 两位人物 | 小幅拖动换角度、滚轮微调距离 | 竹林与云雾成为背景，远山只保留淡影 |
| 指针交互 | 近处的环境点 | 移动指针 | 周围粒子轻微排开；主体人物不被指针任意拆散 |
| 地面交互 | 空地粒子 | 点击地面 | 一圈低幅度涟漪扩散并消失；拖动不触发点击 |
| 人物交互 | 双人动作 | 点击人物或暂停按钮 | 暂停/继续占位动作，环境仍可被探索 |
| 完整详情 | 场地文字与未来内容 | 点击“关于此地” | 全屏内容淡入；不是悬浮信息卡 |
| 返回 | 人物退场、山形重现 | 拉远到阈值，点击全景或 Esc | 人物和近场点淡去，相机升高并返回进入前的视角 |
| 直达与记录 | 五场地导航 | 点击底栏或数字 1–5 | 已寻访的场地做本地记录；返回不清空进度 |

## 三类粒子

1. **结构点**：绑定在山体、竹竿和人物的目标坐标。保持稳定身份，不能每帧随机重生。
2. **空气点**：独立存在于三维空间。提供前后景视差和自由漂移，不能仅作为屏幕噪点贴图。
3. **云雾点**：较大、较淡的局部点簇。在山腰、空地后方构成抽象气氛，不承担人物细节。

疏密控件改变可见点预算，保持同一组坐标与随机种子。静息模式降低环境运动、暂停人物动作，并缩短之后发起的镜头过渡。系统的减少动态效果偏好默认启用静息模式。

## 相机规则

- 总览保存相机位置与观察点，进入后返回该位置。
- 靠近路径有中间抬升/下降点，并检查相机始终高于地形。
- 近场相机以人物胸部附近为观察中心，限制水平角度，避免绕到场景背后。
- 拉远返回只在已抵达的近场触发，不能在飞行途中因距离过大而误退出。
- 新命令接管当前镜头，先清除旧的环绕惯性；不使用永久每帧拉回原位的控制逻辑。

## 后续资产与声音

每个场地配置保留 `sceneUrl`、`actorUrl`、`filmUrl`、`ambientAudio`、`stageAudio`。当前均为空。它们是替换位置，不代表已经实现 SPZ/PLY 解码或电影播放；资产确定后再增加相应加载器和生命周期管理。

声音控件当前不播放音频。`wudao:audio` 事件提供：

- `near`：靠近入口。
- `enter`：抵达空地。
- `leave`：返回山图。
- `enabled`：声音开关改变。

事件详情包括 `arenaId` 和 `enabled`，后续可用于淡入环境声、靠近音轨与场地音乐。

## 验证与下一步

自动检查覆盖主峰与空地高差、平台平整、镜头离地、人物屏幕比例、稳定点数据、导航、过期回调、完整详情页、双语、音轨事件与渲染失败回退。UI 测试使用模拟渲染器边界，不等于真实 GPU 或实际画面的验证。

本轮浏览器自动访问 localhost 再次被已保存的权限策略拒绝，即使用户已在对话中表示允许。没有尝试绕过这一限制，改为本机手动验收。预览服务现已直接运行于本机回环端口；另提供内嵌脚本与样式的单文件 HTML。

已经修复一条 WebGL 状态误报：R3F 的 canvas fallback 子节点会正常挂载，不能在其挂载副作用中报告 WebGL 不可用。新增回归检查验证备用节点不会把成功创建的画布判为失败。修复后，用户已确认可以看到高山与五个入口。

当前有 32 项自动检查通过（包含历史版本回归），生产构建与单文件构建通过。单文件已检查脚本语法、根节点、内嵌样式，且没有外部脚本或样式标签。真实 GPU 帧率尚未测量，不承诺特定设备上的帧率。

正确的后续次序：

1. 在可操作 Demo 中确认山的尺度、五处空地的分布、人物比例与返回节奏。
2. 选一处场地制作 World Labs 或 GLB 环境资产，验证点云/高斯风格，不一次生成全部区域。
3. 让局部环境接替当前程序占位背景，保留已确认的相机与交互。
4. 制作电影动作资产、音乐与完整内容，再扩展至其余场地。
